Unsupervised Learning

A branch of Machine Learning where the algorithm learns from unlabeled data. The model identifies patterns, structures, and relationships without any predefined output variable. The goal is to discover the inherent structure hidden within the dataset.

🫧

Clustering

A technique that groups similar data points together into clusters. Points within the same cluster share common characteristics, while points from different clusters are dissimilar. Clustering enables segmentation and exploratory data analysis.

⚙️

K-Means Algorithm

The most popular clustering algorithm. It partitions data into K groups by iteratively assigning each point to its nearest centroid and recalculating the centroids until convergence. Simple, scalable, and highly effective.

🎯

Centroids

A centroid is the geometric center of a cluster — the mean of all data points assigned to that group. At each iteration, centroids are recalculated to minimize intra-cluster distance. They act as cluster "representatives".

📏

Euclidean Distance

The most common distance metric used in K-Means. It measures the straight-line distance between two points in feature space. Each data point is assigned to the cluster whose centroid is closest by Euclidean distance.

🔄

Iterative Process

K-Means alternates between two steps: Assignment — each point is assigned to the nearest centroid, and Update — centroids are recalculated as group means. This loop continues until cluster assignments stabilize.

Euclidean Distance Formula

Given two points P = (x₁, y₁) and Q = (x₂, y₂) in a 2D feature space, the Euclidean distance is:

d(P, Q) = √( (x₂ − x₁)² + (y₂ − y₁)² )

This formula extends naturally to higher dimensions. In K-Means, each data point is assigned to the centroid with the smallest Euclidean distance.

K-Means Step-by-Step

  • Choose K — decide how many clusters to form and initialize K centroids (randomly or manually).
  • Calculate distances — for each data point, compute the Euclidean distance to every centroid.
  • Assign clusters — assign each point to the cluster of its nearest centroid.
  • Update centroids — recalculate each centroid as the mean of all points assigned to it.
  • Check convergence — if assignments did not change (or variance reduction is negligible), stop; otherwise return to step 2.

Variance & Convergence

K-Means minimizes inertia (also called within-cluster sum of squared distances). After each iteration, the total variance decreases. When the reduction becomes negligible or zero, the algorithm has converged. A variance plot across iterations visualizes this convergence.

Variance = Σ d(xᵢ, centroid_k)²
